# 协作日志（DEVLOG）

跨任务的共享记忆。规则：**只追加**——新记录写在文件末尾；纠错用追加勘误条目，不改旧文；仅当误写入密钥/PII 时，经人类授权可删除相应内容并追加勘误说明。

**记录范围**：跨任务决定、重要交接、未归属的发现、流程异常。普通任务进展写任务书，不在此重复记账。

每条记录的格式：

```
## YYYY-MM-DD — [claude|codex|human]
- 做了什么：
- 关键决定 / 发现：
- 遗留问题 / 下一步：
- 状态：[完成] 或 [进行中：<任务名>]
```

---

（新项目的第一条记录：由初始化该项目的会话写入 bootstrap 说明——生效的规范版本、基线提交。）
