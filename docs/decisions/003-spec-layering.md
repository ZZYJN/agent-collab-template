# ADR-003: 规范分层——根规范 + 受控子规范（收窄 ADR-001 表述）

日期：2026-08-31 ｜ 提出者：[claude]（依据 Codex 二轮审计）｜ 批准人：张焯元 ｜ 状态：已采纳 ｜ 取代：ADR-001 的"共同规范只写 AGENTS.md"表述

## 背景

ADR-001 的原始表述是"共同规范只写在 AGENTS.md"。规范成长后的实际结构已是两层：AGENTS.md（常驻上下文）+ docs/workflow.md（按需加载）。二轮独立审计指出旧表述与现实直接冲突。

## 决定

- ADR-001 的结论收窄为：**代理入口文件单一来源**——各 agent 的入口一律导入/指向 AGENTS.md，不复制内容。此部分继续有效。
- 规范体系为两层：AGENTS.md 是**根规范与索引**；docs/workflow.md 等为**受控子规范**（修改同样须人批准）。规则冲突时以根规范为准。

## 理由与被否掉的替代方案

- 全部塞回 AGENTS.md：违反 ≤150 行的常驻预算，每个会话都要为此付 token 成本，否。
- 维持旧表述不动：与现实不符，已被审计标记为矛盾源，否。

## 影响

- CLAUDE.md 等入口文件的说明文字同步更新。
- 后续新增受控子规范，须在 AGENTS.md「流程入口」挂触发条件并声明受控地位。
